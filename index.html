Como usar o método
  1. Construção: teoria, grifos enxutos e questões do tópico durante a primeira passada.
  2. Consolidação, primeiro ciclo: questões por tópico da banca e área pertinente, começando pelos últimos cerca de 8 anos. Corrija e marque erros, acertos difíceis e novidades; depois consulte a lei nesses pontos.
  3. Consolidação, ciclos seguintes: misture os tópicos para treinar recuperação ativa; amplie anos e áreas da mesma banca conforme a pertinência.
  4. Manutenção: continue fazendo questões periodicamente. Use as estatísticas por tópico do site de questões, sem cadastrar cada erro aqui.
  5. Anki: deixe as revisões com o Anki; crie cartões seletivamente, sem contá-los neste painel.

Salvar e recuperar pelo GitHub

Conecte um repositório para guardar as matérias, o planejamento, as revisões e as sessões no arquivo ciclo-estudos/dados.json. Cada gravação cria uma versão no GitHub.

Ainda não conectado. Seus dados estão protegidos pela cópia local.

O token fica somente na memória desta aba, não entra nos arquivos publicados e não é salvo no navegador. Ao reabrir o site, conecte novamente para recuperar e continuar salvando no GitHub. Sem conexão, as alterações ficam pendentes na cópia local.

Como preparar a conexão
  1. Crie um repositório para os dados. Prefira um repositório privado separado do site publicado no GitHub Pages.
  2. No GitHub, acesse Fine-grained personal access tokens e crie um token com validade e acesso somente a esse repositório.
  3. Em Repository permissions → Contents, selecione Read and write.
  4. Preencha o repositório e cole o token no campo acima. O botão conectar vai ler os dados existentes e sincronizar suas alterações.

Se o repositório de dados for público, o histórico também será público. Uma regra que bloqueie gravações diretas na branch pode impedir a sincronização.

Backup e mudança de endereço

Use o backup para levar os dados deste endereço para o GitHub Pages ou guardar uma cópia. O arquivo inclui matérias e sessões, sem a credencial.

O cronograma é uma sugestão semanal. As sessões ficam na cópia local e são gravadas no GitHub quando você conecta e sincroniza.
